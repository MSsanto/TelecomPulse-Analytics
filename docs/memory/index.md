# TelecomPulse — Project Memory

This directory stores durable, human-readable project memory.

## Rules

- Git/Markdown is the canonical memory representation.
- Only validated outcomes may become canonical.
- Evidence and dates are required for durable decisions.
- Current source evidence outranks remembered conclusions.
- Secrets and sensitive data must not be stored here.
- Superseded decisions remain traceable.

## Categories

- `decisions/` — architecture/product/data decisions;
- `procedures/` — repeatable operational workflows;
- `gotchas/` — known failure modes;
- `handoffs/` — cross-session/agent baton;
- `gates/` — sprint/homologation outcomes.
